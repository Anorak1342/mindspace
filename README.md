# Mindspace

A responsive study dashboard built with plain HTML, CSS and JavaScript. No build tools or dependencies are required.

## Features

- Editable flashcard decks saved in your browser
- Focus timer with short-break mode
- Quick notes saved locally on your device
- Pair Up memory game
- Reflex Check reaction-time game
- Number Dash arithmetic game
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait a minute or two for GitHub Pages to publish the site.

Your site should appear at `https://anorak1342.github.io/mindspace/` once deployment succeeds.

Decks and notes are stored in local browser storage. They do not automatically sync between devices.
